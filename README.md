# Mensaje Colegas

Redacta mensajes de WhatsApp para médicos del Servicio de Urgencias con el encabezado según urgencia:

| Encabezado | Cuándo |
|---|---|
| 👀🚨🚨‼️ *Estimados colegas* | Cobertura de turno con menos de 72 h |
| 👀🚨‼️ *Estimados colegas* | Cobertura entre 3 días y 1 semana, u otro mensaje urgente |
| 👀‼️ *Estimados colegas* | Cobertura con más de 7 días, u otro mensaje sin urgencia |

En cobertura de turnos, el turno (día, fecha y horario) y *con pago de horas extras* siempre van en negrita.

- **App nativa iPhone/iPad** (`MensajeColegas/`): SwiftUI + Apple Intelligence en el dispositivo (iOS 26+). Redacta y corrige sin clave ni internet.
- **PWA** (`index.html`): un solo archivo offline. Ábrela en Safari → Compartir → Añadir a pantalla de inicio.
